================================================================================
                    WASTEWISE PROJECT - TECHNOLOGIES USED
================================================================================

PROJECT OVERVIEW
----------------
WasteWise is a full-stack waste management system with separate frontend and 
backend applications, built using modern web technologies.

FRONTEND STRUCTURE
-----------------
/src/
  ├── components/          → React, TypeScript, Tailwind, shadcn-ui
  │   ├── admin/          → Admin dashboard components
  │   ├── auth/           → Login/Register forms (React Hook Form, Zod)
  │   ├── dashboard/      → Dashboard widgets (Recharts)
  │   ├── map/            → Leaflet, React Leaflet
  │   ├── qr/             → QRCode libraries
  │   └── ui/             → shadcn-ui components
  ├── pages/              → React Router pages
  ├── contexts/           → React Context API
  ├── hooks/              → Custom React hooks
  └── lib/                → Utilities, API client (TanStack Query)

BACKEND STRUCTURE
----------------
/backend/
  ├── models/             → Mongoose schemas
  ├── routes/             → Express routes, express-validator
  ├── middleware/         → JWT authentication
  ├── uploads/            → Multer file storage
  └── server.js           → Express app, CORS, MongoDB connection

KEY FEATURES & TECHNOLOGY MAPPING
---------------------------------
1. User Authentication
   - Frontend: React Hook Form, Zod, Context API
   - Backend: JWT, bcryptjs, Express middleware

2. Waste Management
   - Frontend: Forms, Image upload, QR generation
   - Backend: Mongoose models, Multer, Express routes

3. Real-time Tracking
   - Frontend: Leaflet maps, React Leaflet
   - Backend: MongoDB geospatial queries

4. QR Code System
   - Frontend: qrcode.react, html5-qrcode
   - Backend: Verification code generation

5. Dashboard Analytics
   - Frontend: Recharts, TanStack Query
   - Backend: MongoDB aggregation pipelines

6. Mobile Support
   - Frontend: Responsive Tailwind CSS, html5-qrcode
   - Backend: Mobile-optimized API responses

7. Data Visualization
   - Frontend: Recharts for graphs and charts
   - Backend: Statistics calculation APIs

8. File Uploads
   - Frontend: Form handling with React Hook Form
   - Backend: Multer middleware
