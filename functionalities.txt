================================================================================
                    WASTEWISE - DASHBOARD FUNCTIONALITIES
================================================================================

PROJECT OVERVIEW
----------------
WasteWise is a comprehensive Smart Waste Management System with four main user
dashboards: Citizen, Municipal Worker, Recycling Center, and Admin. Each 
dashboard has specific functionalities tailored to the user's role.

================================================================================
                        1. CITIZEN DASHBOARD FUNCTIONALITIES
================================================================================

LOCATION: /src/pages/CitizenDashboard.tsx

A. PROFILE MANAGEMENT
---------------------
1. View Profile Information
   - Display name, house ID, email, phone, address
   - View municipal ID assignment
   - View QR code for waste collection

2. Edit Profile
   - Update personal information
   - Change contact details
   - Update address

B. WASTE MANAGEMENT
-------------------
3. Upload Waste
   - Select waste type (organic, plastic, paper, metal, glass, mixed)
   - Enter weight in kg
   - Add location (optional)
   - Add description (optional)
   - Upload waste image (optional)
   - Submit waste collection request

4. View Waste History
   - See all uploaded waste records
   - Filter by status (pending/collected)
   - Filter by waste type
   - View detailed information:
     * Waste type and weight
     * Upload date and time
     * Collection date and time (if collected)
     * Location and description
     * Waste ID for tracking
     * Status indicators

5. Generate Verification Code
   - Create 6-digit verification code for pending waste
   - Copy code to clipboard
   - Share code with municipal worker for collection
   - View code in waste history

6. View Statistics
   - Today's waste collected (kg)
   - Total waste collected (kg)
   - This month's collection (kg)
   - Recycling rate percentage

C. VEHICLE TRACKING
-------------------
7. Real-time Vehicle Tracking
   - View municipal waste collection vehicles on map
   - See vehicle locations in real-time
   - Track collection routes
   - View vehicle status

D. WASTE DUMPING REPORTS
-------------------------
8. Report Illegal Dumping
   - Capture current GPS location
   - Enter location manually
   - Add description of dumping
   - Upload photo evidence (optional)
   - Submit report to municipality

9. View My Reports
   - See all submitted reports
   - View report status (pending/resolved)
   - See resolution details
   - View uploaded photos
   - Check waste collected from reports

E. PENALTIES MANAGEMENT
-----------------------
10. View Penalties
    - See all penalties issued
    - View penalty details and reasons
    - Check penalty amounts
    - View penalty status (pending/paid)
    - See penalty dates

F. ECO-SHOPPING
---------------
11. Browse Eco Products
    - View eco-friendly products from recycling centers
    - Filter by category (bags, containers, furniture, decor, stationery)
    - See product details, prices, and images
    - View product materials and descriptions

12. Purchase Products
    - Add products to cart
    - Enter delivery address
    - Add phone number
    - Add order notes
    - Complete purchase

13. View Purchase History
    - See all product purchases
    - View order status (pending/confirmed/completed/cancelled)
    - Generate verification code for order pickup
    - Copy verification code
    - Cancel pending orders
    - View order details and delivery information

G. DATA MANAGEMENT
------------------
14. Auto-refresh Dashboard
    - Automatic data refresh every 30 seconds
    - Manual refresh option
    - View last update timestamp
    - Online/offline status indicator

15. Data Recovery
    - Recover data from server if needed
    - Fix data inconsistencies
    - Cache management
    - Offline data persistence
